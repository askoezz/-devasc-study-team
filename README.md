## Содержание работ

### 1. Linux и основы DEVASC
- Установка и запуск виртуальной машины DEVASC.
- Работа с терминалом Linux.
- Управление файлами и каталогами.
- Настройка прав доступа.
- Поиск и анализ текстовых данных с помощью grep.

### 2. Python
- Работа с переменными, типами данных и структурами.
- Использование условий, циклов и функций.
- Создание собственных классов и объектов.
- Написание автоматических тестов с помощью unittest.
- Обработка данных XML, JSON и YAML.

### 3. Инструменты разработки
- Работа с виртуальными окружениями Python.
- Установка библиотек и управление зависимостями через pip.
- Использование Git для контроля версий.
- Создание веток, коммитов и слияний.
- Разрешение конфликтов Git.
- Публикация проектов на GitHub.

### 4. Cisco DevNet
- Изучение образовательных ресурсов Cisco DevNet.
- Знакомство с Sandbox, Code Exchange и платформами Cisco.

## Используемые технологии

- Ubuntu Linux
- Python 3
- Git и GitHub
- Oracle VirtualBox
- VS Code
- Python unittest
- XML, JSON, YAML
- pip и virtualenv

## Цель проекта

Получение практических навыков разработки, автоматизации, работы с Linux, Python и инструментами Cisco DevNet в рамках подготовки к сертификации DEVASC.
