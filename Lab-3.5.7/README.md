# Лабораторная работа 3.5.7 — Создание модульного теста Python

## Цель работы
Изучить возможности библиотеки unittest и научиться проверять работу функций с помощью автоматических тестов.

## Выполненные задания

### Часть 1. Изучение unittest
Изучен модуль unittest, класс TestCase и механизм обнаружения тестовых методов.

### Часть 2. Создание функции поиска
Создан файл recursive_json_search.py с функцией json_search(), выполняющей рекурсивный поиск ключей в структуре данных.

### Часть 3. Создание тестов
Создан файл test_json_search.py с тремя тестами:
- Проверка нахождения существующего ключа.
- Проверка отсутствия несуществующего ключа.
- Проверка типа возвращаемого значения.

### Часть 4. Исправление ошибок
Исправлена рекурсивная функция поиска. Для сохранения найденных результатов использована внутренняя функция inner_function().

## Файлы лабораторной работы

- test_data.py
- test_json_search.py

## Результат
Автоматическое тестирование выполняется с помощью unittest.
