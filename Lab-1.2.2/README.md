# Lab 1.2.2 — Linux Review

## Цель работы

Получение практических навыков работы с командной строкой Linux, файлами, каталогами, правами доступа и обработкой текстовых данных.

## 1. Работа с файлами и каталогами

В ходе работы были выполнены операции:

- Создание каталогов с помощью mkdir.
- Создание файлов с помощью touch.
- Запись текста с помощью echo.
- Просмотр содержимого через cat.
- Копирование файлов с помощью cp.
- Перемещение и переименование файлов с помощью mv.

Создан файл test.txt с содержимым Hello DEVASC.
Также был создан test_copy.txt.

## 2. Права доступа

Изучена команда chmod.

Выполнено изменение прав доступа:
- chmod 600
- chmod 644

## 3. Поиск файлов

Использовалась команда find для поиска файлов в каталогах.

## 4. Обработка логов с помощью grep

Создан файл sample.log с тестовыми событиями:

- INFO User admin logged in
- ERROR Failed password for root
- INFO User student logged in
- ERROR Connection refused
- WARNING Disk space is low
- INFO System started

Выполнены запросы grep:

| Команда | Результат |
|---|---|
| grep "ERROR" | Найдены 2 строки |
| grep -c "ERROR" | 2 |
| grep "^INFO" | Найдены 3 строки |
| grep -c "User" | 2 |
| grep -E "ERROR\|WARNING" | Найдены 3 строки |

## 5. Системная информация

Изучены команды:

- whoami
- hostname
- date
- uname -a
- df -h
- free -h

## Результат

В ходе лабораторной работы получены практические навыки работы с Linux, управления файлами и каталогами, настройки прав доступа, поиска информации и анализа текстовых журналов.
