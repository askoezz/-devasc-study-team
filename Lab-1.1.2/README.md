# Lab 1.1.2 — Install the Virtual Machine Lab Environment

## Цель работы

Установка и настройка виртуальной машины DEVASC для выполнения лабораторных работ Cisco.

## 1. Подготовка среды виртуализации

Использовались:
- Oracle VirtualBox
- DEVASC Virtual Machine
- Ubuntu Linux

## 2. Запуск DEVASC VM

Выполнено:
- Импорт виртуальной машины в VirtualBox.
- Запуск DEVASC VM.
- Загрузка Ubuntu.
- Проверка работы терминала.
- Ознакомление с интерфейсом виртуальной машины.

## 3. Инструменты разработки

В виртуальной машине использовались:
- Terminal Emulator
- Python 3
- Git
- VS Code
- Chromium Browser

## 4. Использование виртуальной машины

DEVASC VM использовалась для выполнения лабораторных работ по Linux, Python и Git.

## Результат

Виртуальная среда DEVASC подготовлена и используется для выполнения практических заданий Cisco.
