## Part 3. Sandboxes

- Тип Sandbox для частного доступа к пакетным лабораторным работам: Reservation Sandboxes
- Ресурс помощи: DevNet Sandbox Community Forum

- URL подключения к ACI: https://sandboxapicdc.com/

Большие ресурсы не рекомендуется загружать из-за ограничений ресурсов среды, времени загрузки и доступного пространства.
