# Лабораторная работа 3.6.6 — Разбор различных типов данных с помощью Python

## Цель работы
Изучить способы обработки XML, JSON и YAML с помощью Python.

## Часть 1. Разбор XML
Создан скрипт parsexml.py с использованием ElementTree и регулярных выражений.
Из XML-файла извлечены значения default-operation и test-option.

## Часть 2. Разбор JSON
Создан скрипт parsejson.py с использованием библиотеки json.
Извлечены значения access_token и expires_in.
Данные JSON преобразованы в формат YAML.

## Часть 3. Разбор YAML
Создан скрипт parseyaml.py с использованием библиотеки yaml.
Извлечены значения access_token и expires_in.
Данные YAML преобразованы в формат JSON.

## Файлы лабораторной работы
- myfile.xml
- myfile.json
- myfile.yaml
- parsexml.py
- parsejson.py
- parseyaml.py

## Результат
Изучен разбор и преобразование данных в форматах XML, JSON и YAML.
